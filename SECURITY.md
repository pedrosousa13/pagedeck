# Security

## Reporting a vulnerability

Report a vulnerability in Pagedeck privately, through GitHub's private
vulnerability reporting:

<https://github.com/pedrosousa13/pagedeck/security/advisories/new>

Do not open a public issue, pull request or discussion about it. A private
report is visible only to you and the maintainers until an advisory is
published.

Say which package and version are affected, what an attacker can do, and the
steps or the site config that show it.

There is no email address for reports, and no promised response time.
Pagedeck is maintained on a best-effort basis.

## Fixes and supported versions

A fix is released as a new version of every public package, because every
public package is released at one version. It reaches your site when you
[upgrade every `@pagedeck/*` package together](https://page.deck.cool/docs/how-to/upgrade-pagedeck/).

The supported Node.js, React and browser versions are on
[Support and compatibility](https://page.deck.cool/docs/reference/support/).
